En index.php (líneas 20-43):

// Define qué rutas NO necesitan login
$rutasPublicas = [
    'login' => ['index', 'login']
];

// Si necesita login y NO hay sesión → ERROR 401
if ($necesitaLogin && !isset($_SESSION['usuario_id'])) {

    // Mostrar página 401
    exit;
}

1. MIDDLEWARE (index.php):
   - Verifica sesión ANTES de cargar controladores
   - Si no hay sesión → 401
   - Si hay sesión → continúa

2. PATRÓN MVC:
   - Modelo: accede a BD
   - Vista: muestra HTML
   - Controlador: une modelo y vista

3. SANITIZACIÓN:
   htmlspecialchars(trim($dato), ENT_QUOTES, 'UTF-8')

4. PREPARED STATEMENTS:
   $stmt->execute([':parametro' => $valor])

5. SESIÓN:
   Solo guarda: $_SESSION['usuario_id']
   NO guarda la contraseña
